Onboard memory

Your keyboard and mouse can store settings inside themselves, so they work on any computer, even without Prism. A backup copies everything stored on both devices to this computer. It only reads: nothing on the devices changes.

Restore… puts a backup back onto your devices: Prism shows what would change, asks first, and makes a fresh backup before writing.
